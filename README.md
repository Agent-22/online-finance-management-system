# online-finance-management-system
A web-based application designed to help users manage their personal finances efficiently by tracking income, expenses, budgets, and savings. It provides a centralized platform to monitor financial activities, analyze spending habits, and make smarter financial decisions through organized records and insightful reports.




## ✨ Features

- 🔐 **User Authentication:** Secure Sign Up, Sign In, and session management.
- 📊 **Dynamic Dashboard:** Real-time summary cards calculating Total Balance, Total Income, and Total Expenses.
- 📑 **Transaction Management:** Add, view, and delete personal financial transactions (Income & Expenses).
- 🎯 **Budget Control:** Set custom monthly budget limits with automatic threshold alerts.
- 👤 **Account Profile:** View active user account details and profile information.
- 📱 **Multi-Page Layout:** Clean sidebar navigation supporting multiple views (Dashboard, Transactions, Budgets, Account).



## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Styling:** Custom CSS (Modern UI/UX with Flexbox & Grid)
- **Storage / State:** Browser LocalStorage
- **Backend:** Java 
- **Database:** MySQL
- **Version Control:** Git & GitHub

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Ensure you have the **`index.html`** file in your project folder.
3. Double-click **`index.html`** to open it directly in any modern web browser (Chrome, Firefox, Edge, Safari).
4. Sign up for a new account, log in, and start tracking your finances!
